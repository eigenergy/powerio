# PowerIO 0.11.11 release notes

PowerIO 0.11.11 is a patch release of conversion fixes. XIIDM output now
gives every piece of equipment it writes a terminal, or leaves it out and
says so, instead of writing files that PowerIO and PowSybl reject. Egret
time-series output writes `null` for an unlimited branch rating instead of a
`0` that Egret reads as a zero limit. CGMES output states a generated phase
tap changer's reactance on the right base. OpenDSS decks supplied from memory
find their include files when the names differ only in letter case, and
GridLAB-D and OpenDSS recognize absolute include paths written on any
platform. C ABI 7, PowerIO IR version 2 and the IR schema
`pio-ir/2/0.11.8/schema.json` are unchanged. PowerIO.jl follows this release
with the same tested binary artifacts.

The [curated changelog](../../CHANGELOG.md#01111) gives each change in full.

## What is new

### XIIDM output gives every equipment a terminal

An XIIDM file places each load, generator, line, and other piece of equipment
on a bus or node through its terminal. PowerIO builds that placement from the
network's substation data, and when a network has none, such as one read from
a PSS/E RAW file without substation records, it derives one. The derivation
skipped static var compensators, so a compensator read from a PSS/E FACTS
record was written with no terminal, and PowerIO refused to read its own
output (#831, #832).

The same gap appeared with partial substation data, such as PSS/E substation
data that names the terminals of only some equipment. Equipment without a
stated terminal was written without one, and a load or generator at a bus
outside every stated voltage level was left out of the file without a word.
The writer now gives each such load, generator, battery, shunt, static var
compensator, line, and transformer a terminal on its bus and reports it as
`EMIT.XIIDM.VALUE_DEFAULTED`. In a node breaker voltage level, where a node
holds one terminal, the equipment gets a new node joined to the bus's node by
an internal connection. Equipment that still has no bus or node is left out
and reported as `EMIT.XIIDM.RECORD_DROPPED`, and every equipment writer now
checks its terminals before writing, so a file missing a terminal can no
longer be written silently.

A static var compensator read from PSS/E can control the voltage of a remote
bus. When that bus has no terminal for the compensator to name, the writer
now reports `EMIT.XIIDM.FIELD_DROPPED`, as the generator and shunt writers
already did, and the compensator controls the voltage at its own terminal to
the remote bus's setpoint.

### Egret output writes `null` for an unlimited rating

PowerIO stores an unlimited branch rating as `0`. Egret reads `0` as a zero
thermal limit and `null` as unlimited, so a time series that mixed limited and
unlimited points was written with zeros that Egret enforced as limits of zero.
Canonical output now writes, for example, `[null, 150.0]`, for long-term,
short-term, and emergency ratings, and the reader accepts `null` points
(#828).

A numeric zero in a native Egret file still reads as unlimited, as in earlier
0.11 releases, because the 0.11 branch model has no way to hold a zero limit.
Refusing such input is planned for 0.12. A PowerIO IR document made from an
Egret file with a zero limit holds an unlimited rating; regenerate it from
the original Egret file if the zero limit matters. The
[time series chapter](../src/time-series.md) has the details.

### CGMES phase tap changers state their reactance on end 1's base

When PowerIO writes a phase shifting transformer that has no phase tap
changer of its own, it writes a new one. That changer stated its reactance on
a different base than the transformer's end 1, so reading the file back
reported a tap-step reactance deviation that was not there whenever the
transformer's tap ratio was not one. The changer now uses end 1's base. No
branch value changes (#829).

The 0.11.10 release notes also now say that CGMES files written by 0.11.0
through 0.11.9 with a nonzero to-side transformer shunt read back with a
different shunt, rather than naming only 0.11.9.

### OpenDSS includes match supplied files regardless of letter case

Decks written on Windows often name an include in a different letter case
than the file, such as `Redirect linecodes.dss` for `LineCodes.DSS`. A deck
read from disk on a case-sensitive file system still needs the exact name,
but a deck supplied from memory, as a file tree (`Source::from_memory_tree`)
or as a main buffer with named companions (`Source::with_named_buffer`,
Python's named buffers, and C's `pio_source_from_memory_with_buffers`), now
matches a `Redirect`, `Compile`, or `Buscoords` name to a supplied file that
differs only in letter case. Such an include used to fail with
`READ.DSS.INCLUDE_LOAD_FAILED` and leave an incomplete network. An exact name
still wins, and a name that matches several supplied files is refused rather
than guessed (#812).

### Absolute include paths are recognized on every platform

A GridLAB-D or OpenDSS case written on one system is often read on another.
An include path now counts as absolute on every platform when it starts with
`/` or `\`, including a network share such as `\\server\share`, or with a
drive letter and a separator (`C:\` or `C:/`). GridLAB-D used to recognize
only a leading `/`, so on Windows a project with an include such as
`C:\feeder\load.glm` was relocated when it should have been refused, and
OpenDSS missed `C:\` paths on Linux and macOS and `/` paths on Windows
(#832).

### Smaller fixes

The architecture map check, which compares the crate graph with the
documented one, now runs on Windows, where cargo reports paths with
backslashes (#833, #834). The Python package metadata no longer lists Python
3.9 and 3.10, which the package stopped supporting when it began requiring
Python 3.11.

## Behavior changes

- XIIDM output gives equipment without a stated terminal a terminal on its
  bus and reports `EMIT.XIIDM.VALUE_DEFAULTED`. Equipment that still has no
  bus or node is left out of the file and reported as
  `EMIT.XIIDM.RECORD_DROPPED`. 0.11.10 wrote such equipment without a
  terminal, which PowerIO and PowSybl reject, or left it out without a
  report.
- Egret time-series output writes `null`, not `0`, for an unlimited branch
  rating point. PowerIO 0.11.10 and earlier reject `null` rating points, so
  read this output with 0.11.11 or newer. Native Egret accepts it.
- CGMES files written by 0.11.0 through 0.11.10 that contain a generated
  phase tap changer still state the old reactance and still read back with
  the false deviation. Regenerate them from the original network, or from a
  PowerIO IR document saved before the export, to remove it.
- An OpenDSS deck supplied from memory resolves includes whose names differ
  from a supplied file only in letter case. Decks read from disk are
  unchanged.
- A GridLAB-D project with a Windows absolute include such as `C:\x.glm` is
  refused when written as a relocated project on every platform.

## Compatibility

C ABI 7 and PowerIO IR version 2 are unchanged, and IR documents keep naming
the `pio-ir/2/0.11.8/schema.json` catalog. No public item is renamed or
removed. The minimum supported Rust version stays 1.89 and the minimum
Python version stays 3.11.

## Release validation

Source CI, native Python wheels and smoke tests, and paired Julia source tests
run before the release tag. The tag workflow then runs PowerIO.jl against all
five packaged C library archives before it creates a draft. Publication and
the protected registry approvals are separate steps; passing source checks
alone does not mean a package has been published.
