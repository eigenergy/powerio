# PowerIO 0.12.2 release notes

This patch qualifies OpenDSS transformer snapshots and makes retained regulator controls distinguishable from invalid property values. Package and PowerIO IR versions are 0.12.2; compatibility remains within the 0.12.x series.

Finite transformer terminal admittances support two or three windings with the existing WYE/DELTA, tap, neutral and leakage checks. OpenDSS inputs apply the default small grounding admittance or the explicitly written `ppm_antifloat` coefficient. Unsupported winding counts, malformed coefficients and unsupported BMOPF autotransformer grounding return explicit errors.

Twenty-three synthetic OpenDSS reference cases compare every terminal-admittance entry for two and three windings, controlled single-phase units, unequal taps, floating neutrals and omitted, zero, positive and negative coefficients. Their generator and synthetic-source license are included. Tellegen also compares full-network voltages, transformer terminal currents and losses in six additional three-winding cases and three controlled single-phase cases.

Retained regulator controls report `READ.DSS.CONTROL_NOT_EXECUTED`; the equipment keeps its written taps. This permits an explicit fixed-settings calculation without suppressing unrelated invalid-property warnings. Missing transformer targets still report a dropped reference. PowerIO does not run regulator controls.

The C ABI release constants and PowerIO IR schema identify 0.12.2. Existing record layouts and published schema files are unchanged.
