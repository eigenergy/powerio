# PowerIO 0.11.3 release notes

PowerIO 0.11.3 reads and writes the three PSS/E contingency analysis files:
the contingency description file (`.con`), the subsystem description file
(`.sub`), and the monitored element file (`.mon`). The Rust crates parse each
file into typed sets, resolve its statements against a network, and expand
automatic specifications into explicit cases. The `powerio` facade carries the
three files as value types, the `powerio contingency` commands resolve and
expand a set, and the additive IR catalog `pio-ir/2/0.11.3` states the three
new structural types. The Python and C bindings reach the same files. Python
reports a module's canonical structural name as `PioModule.type_name` and
builds JSON-ready diagnostic records with `powerio.diagnostic_record` and
`powerio.diagnostic_records`. Dependencies move to their current majors, and
CI fails on a RUSTSEC advisory against the dependency graph. C ABI 7 and
PowerIO IR generation 2 remain unchanged.

The [curated changelog](../../CHANGELOG.md#0113) records this release's changes.
PowerIO.jl 0.11.3 accompanies this release.
