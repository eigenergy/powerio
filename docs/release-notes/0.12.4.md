# PowerIO 0.12.4 release notes

This patch fixes an AC power flow specification, three writers and a matrix check, and moves the XML readers to quick-xml 0.42. Package and PowerIO IR versions are 0.12.4; compatibility remains within the 0.12.x series.

`AcPfInstance::from_network` gives a bus coded PV with no in service generator the PQ specification, as MATPOWER and pandapower give a bus with no generator. Such a bus was held at its stated voltage with reactive power no device supplies. Only generators count as voltage controllers: an HVDC line terminal, a static var compensator or a generator regulating the bus from elsewhere does not keep it PV. The new `AcPfInstance::voltage_control_diagnostics` returns one `TRANSFORM.INSTANCE.ASSUMPTION` diagnostic per such bus. An instance built from explicit specifications, including one read from a stored document, keeps the specifications it states.

OpenDSS output writes one single phase generator per phase when a generator's phase powers or reactive limits differ, because OpenDSS spreads a multi phase generator equally over its phases. Each part states the line to neutral value of the generator's stated `kv` on a wye connection and the stated value on a delta. A generator with equal phase powers is written as before.

OpenDSS output writes a closed PMD switch whose impedance and shunt matrices are all zero as the ideal switch pair, with `EMIT.DSS.IDEAL_SWITCH_EQUIVALENT`. It wrote a zero impedance line, which OpenDSS rejects with error 183. An open switch with zero matrices, and a closed switch with zero series matrices and a nonzero shunt, are written as before.

The pandapower JSON writer states `tap_dependency_table = false` for every transformer. pandapower 3.0 and later warned on `runpp` that the column was missing.

`check_sddm` reports false for a matrix with a NaN or infinite stored value. A NaN off the diagonal, or a NaN or infinite diagonal, passed before.

The XIIDM reader converts a document in a declared single-byte encoding to UTF-8 once before reading it. The byte offset in a read error for such a document counts bytes of the converted text. A byte that is invalid in the document's encoding is refused wherever it is, including in a comment or a skipped element. UTF-16 is refused as before.

The C ABI release constants and the PowerIO IR schema identify 0.12.4. The schema's content is the 0.12.3 schema with the new identifier; the C ABI gains no symbol.
