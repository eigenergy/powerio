# PowerIO 0.12.1 release notes

PowerIO 0.12.1 is a patch release in the 0.12.x series. It only adds to the
public APIs, and every document that 0.12.0 read still reads.

- **Three-phase pandapower networks** (#866, part 1 of #846, by
  Stephan Kohlhaas). Documents with `asymmetric_load`, `asymmetric_sgen` or
  `res_bus_3ph` rows read into a `MulticonductorNetwork` under the
  `pandapower-json` token. Buses, lines, external grids, loads and static
  generators are mapped. A three-phase document with tables only the balanced
  reader maps (transformers, shunts, generators, storage, DC lines) still
  reads balanced, as in 0.12.0. The 0.12.1 IR schema adds `pandapower-json`
  to the distribution source formats.
- **Wire and cable line constants**. OpenDSS tape-shielded cables (`TSData`)
  are calculated beside overhead and concentric-neutral conductors, and
  distribution CIM and MG-RAVENS segments described by a wire spacing and
  wire or cable catalog entries take the impedance the same OpenDSS line
  constants calculate. The `IEEE13_Assets` conductors of the MG-RAVENS
  examples, stated completely, match OpenDSS to 1e-13. The export itself
  names no neutral wire on ten of its eleven segments, which stay refused
  with the position named, and conversion to another format now refuses
  them in MG-RAVENS as it does in CIM instead of dropping them. Its one
  complete segment matches OpenDSS to 2e-5, the exporter's 1609.3 m mile.
- **Transformer phase clocks**. CIM and MG-RAVENS clocks are the vector
  group shift the physics stamps, so a Dy11 unit (`leadlag=euro`, or clock
  11 in the source) reads, stamps and writes as clock 11, where it was
  written as clock 1 or refused. Other clocks are refused.
- **BMOPF lowercase tokens** (#877). Values from an older BMOPF draft, such as
  `constant_power`, `wye` or `pv`, read as the schema's tokens.
- **Operators from a preparation**. The DC and AC preparations derive their
  incidence, generator to bus map, Laplacian, branch flow matrix, bus
  admittance matrix, pi model blocks and branch flows from the arrays they
  already hold, and the power flow Jacobian builds from an admittance matrix
  and voltages and refreshes from one bus power injection per Newton step, so
  a solver uses PowerIO's operators without rebuilding an indexed network or
  keeping its own copies. Each of these is one calculation inside PowerIO as
  well. The Jacobian refresh is about five times faster. The phase shift
  withdrawal, the pi model block's series admittance derivative and the
  multiconductor line, shunt and capacitor primitives are public as well.
- **Multiconductor transformers in the nodal admittance**. A transformer that
  states leakage now stamps its terminal primitive (WYE and DELTA windings,
  fixed taps, magnetizing branch, neutral impedance; two winding units, the
  BMOPF centre tap and single phase autotransformer), which is public, instead
  of being refused. A unit that states no leakage stays an exact ideal
  constraint. Nameplate, BMOPF phase base and regulator ohmic leakage are one
  calculation. Every transformer quantity (leakage, coil voltage, delta
  orientation and phase shift, magnetizing branch, neutral grounding, the
  primitive itself) lives in `powerio_dist::transformer`, which the nodal
  admittance, the multiconductor OPF, the multiconductor to balanced lowering
  and the SINCAL writer all read, so the power flow and the OPF stamp the same
  unit. The OPF now reads a canonical mixed WYE/DELTA unit's orientation by
  OpenDSS's rule and accepts `leadlag`, `%noloadloss`, `%imag` and a floating
  neutral.
- **One implementation per calculation in the distribution crates**. One
  element connection rule, one voltage zone partition and base flood, one
  dense inverse, one Kron reduction, one simplified Carson equation and one
  set of shielded cable equations now serve every reader, writer and
  builder that repeated them, the GridLAB-D underground and triplex readers
  included.
- **Thermal limits over padded bounds**. An assembly option synthesizes an
  unrated branch's limit over the selected angle difference bounds, as
  PowerModels does after padding them. Off by default.
- **AC OPF preparation speed**. A 78,484 bus case prepares in 32 ms instead
  of 3.8 s.

The [changelog](../../CHANGELOG.md#0121) gives each change in full.
