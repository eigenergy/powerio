# PowerIO 0.12.1 release notes

PowerIO 0.12.1 is a patch release in the 0.12.x series. It only adds to the
public APIs, and every document that 0.12.0 read still reads.

- **Three-phase pandapower networks** (#866, part 1 of #846, by
  Stephan Kohlhaas). Documents with `asymmetric_load`, `asymmetric_sgen` or
  `res_bus_3ph` rows read into a `MulticonductorNetwork` under the
  `pandapower-json` token. Buses, lines, external grids, loads and static
  generators are mapped. A three-phase document with tables only the balanced
  reader maps (transformers, shunts, generators, storage, DC lines) still
  reads balanced, as in 0.12.0. The 0.12.1 IR schema adds `pandapower-json`
  to the distribution source formats.
- **BMOPF lowercase tokens** (#877). Values from an older BMOPF draft, such as
  `constant_power`, `wye` or `pv`, read as the schema's tokens.

The [changelog](../../CHANGELOG.md#0121) gives each change in full.
