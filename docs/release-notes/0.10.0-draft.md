# PowerIO 0.10.0 release notes (draft)

PowerIO 0.10 is the public beta of the 1.0 API. API corrections may land
before 1.0.0 as downstream integrations test the new design.

## Modules and values

Every parse returns `PioModule<PioValue>`. A module contains one typed value
plus its sources, diagnostics, source map, and history. Rust callers that know
the expected kind use `try_into_typed` to move the value and module records
into `PioModule<T>` without serialization or a network copy. A kind mismatch
returns the original dynamic module unchanged.

The 20 stable value identifiers are:

- Networks and repeated network data: `balanced_network`,
  `multiconductor_network`, `balanced_network_time_series`,
  `balanced_operating_point_time_series`,
  `multiconductor_operating_point_time_series`, and
  `balanced_network_scenario_set`.
- Instances: `dc_pf_instance`, `ac_pf_instance`, `dc_opf_instance`,
  `ac_opf_instance`, `mc_ac_pf_instance`, `mc_ac_opf_instance`, and
  `ac_scuc_instance`.
- Solutions: `dc_pf_solution`, `ac_pf_solution`, `dc_opf_solution`,
  `ac_opf_solution`, `mc_ac_pf_solution`, `mc_ac_opf_solution`, and
  `ac_scuc_solution`.

`.pio.json` version 1 stores one module under schema `powerio.module/1`.
Nonfinite floats use the strings `"Infinity"`, `"-Infinity"`, and `"NaN"`.
The reader validates source map references and accepts released 0.9 documents
through the one way upgrade described in the migration guide.

## Parsing, writing, and formats

`Source::open` and `Source::from_bytes` feed the same format dispatcher. An
unchanged module writes its source format byte for byte. A cross format write
returns a diagnostic for each value the destination cannot represent.

Balanced formats produce `BalancedNetwork`; OpenDSS and PMD engineering JSON
produce `MulticonductorNetwork`. DOE GO Challenge 3 produces
`AcScucInstance`, BMOPF produces `McAcOpfInstance`, and DeepMind OPFData
produces `AcOpfSolution`. Supported PyPSA and Egret profiles produce typed
time series. GridFM Parquet datasets produce
`ScenarioSet<BalancedNetwork>` with shared element tables.

## Matrices and problem data

The matrix crates provide DC operators, AC power flow Jacobians,
multiconductor nodal admittance, and sparse PTDF and LODF construction. Public
DC signs match PowerModels:

```text
B         = A * Diagonal(b) * A'
Bf        = Diagonal(b) * A'
p_shift   = A * (b .* shift)
p_bus     = -B * va + p_shift
p_branch  = -Bf * va + b .* shift
```

`powerio-prob` remains matrix free. `powerio-matrix` adds sparse projections
over its instances and owns the DC OPF bundle writer.

## C ABI 6

ABI 6 replaces ABI 5. The machine checked delta has 83 ABI 5 symbols: 70 were
removed, 7 changed signatures, 6 remain unchanged, and ABI 6 adds 91 symbols.
Because existing symbols were removed or changed, this release could not keep
the ABI 5 number.

ABI 6 defines retain and release pairs for every handle, independently owned
child handles, result owned arrays whose views end at release, structured
`PioError` and `Diagnostic` records, panic capture at every external entry
point, and stated concurrency rules. Optional features add behavior without
removing the always linked module and network entry points.

The old package handle and ABI 5 package functions are removed. The private
stored reader contains only the code needed to upgrade released 0.9 documents.

## Python and Julia

Python `powerio.parse(source)` detects the kind and returns a `PioModule`.
`value_type` remains an optional assertion. Native diagnostics use the same
code, severity, message, target, source span, related records, details, and
suggested action as Rust and C.

PowerIO.jl `parse_file(path)` returns `PioModule{T}` and uses Julia dispatch on
`m.value`. `using PowerIO` exports the ordinary accessors. Sparse matrix
builders return `BusMappedMatrix`, which carries the sparse matrix and bus row
mapping.

## Migration

The 0.9 package API, public solver row arrays, old SCOPF projection, and
deprecated parse aliases are not part of 0.10. The Developer Guides list each
removed name beside its replacement and record the ABI 5 history.
