# PowerIO 0.12.3 release notes

This patch lets large OpenDSS cases read and adds an optional per coil generator dispatch column to the multiconductor OPF solution. Package and PowerIO IR versions are 0.12.3; compatibility remains within the 0.12.x series.

A second `New` for an existing general OpenDSS object (LineCode, LoadShape, WireData and the other general classes) edits that object, as OpenDSS does without a message. The reader reports it as one `READ.DSS.OBJECT_REDEFINED` remark per class with a count and the first location, where it reported a `PARSE.DSS.SOURCE_MALFORMED` warning per statement. A second `New` for a circuit element keeps its warning.

`DssReadLimits` raises the OpenDSS include byte limit (64 MiB) and the retained property limit (4,194,304) for a case larger than the defaults. Set it with `ParseOptions::dss_limits` or `powerio_dist::parse_with_dss_limits` in Rust, `dss_max_include_bytes` and `dss_max_properties` in Python's `powerio.parse`, or `--dss-max-include-bytes` and `--dss-max-properties` in the CLI. The defaults are unchanged, and the C ABI has no way to set them.

Lines that fetched the same state of a linecode share one evaluation of it. The public SMART-DS Austin P3U peak region (2,273 files, 152 MB) reads in about 2 s with the limits raised; its bus, line, transformer, load, capacitor, control and fuse names match those DSS C-API 0.14.5 reports.

`McAcOpfSolution::with_generator_coil_active_powers` and `generator_coil_active_powers` carry generator active dispatch per coil, in watts, positive for generation, in the order of the generator's bounds and cost entries. The existing `generator_active_power` column stays per terminal. PowerIO IR gains the optional field `generator_coil_active_power`, written only when recorded; a document without it is unchanged. Readers from 0.12.0 to 0.12.2 refuse a document that states the field. The C ABI gains no symbol; `pio_calculation_solution_get_values` accepts the quantity name `generator_coil_active_power`.

The C ABI release constants and the PowerIO IR schema identify 0.12.3. Published schema files are unchanged.
