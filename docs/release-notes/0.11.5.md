# PowerIO 0.11.5 release notes

PowerIO 0.11.5 loads large CGMES datasets with a 1 GiB default input and
acquisition limit. Indexed import diagnostics and fresh emission reduce repeated
scans, and transformer terminals follow winding numbers even when terminal
sequence numbers differ. Python gains native component counts and source
severing for fresh export, and uses mimalloc for native allocations.

CGMES ZIP archives are held to what they declare. An XML entry must inflate to
exactly its stated size, entry counts are bounded before the archive is
indexed, and archives whose entries overlap or share a name are refused. The
MCP server parses client input under 256 MiB limits unless its operator sets
`POWERIO_MAX_PRIMARY_BYTES` or `POWERIO_MAX_REFERENCED_BYTES`, and it bounds
its directory walk as PowerIO's own listing does; the library defaults stay
1 GiB. Agents now see the reason the server refused a tool call, and
`powerio[mcp]` installs the NumPy and SciPy that `calc_matrix` needs.

Python `parse_display` and the MCP `display` tool remain only for 0.11
compatibility, and 0.12 removes them. Read a PowerWorld `.pwd` display with
`parse`, which returns a `GeoLayer` with its diagnostics.

PSS/E RAW and RAWX switched shunts now interpret MODSW 1 as discrete voltage
control and MODSW 2 as continuous voltage control. Two winding transformers
whose winding 2 ratio is not one now read with the impedance PSS/E solves
with: `r` and `x` scale by the square of that ratio and the tap limits divide
by it, so their branch values change. Reparse the original case if an older
PowerIO IR document carries either earlier reading. The RAW reader also
accepts double-quoted names and circuit ids, and the monitored element reader
accepts the contingency file spelling `MONITOR BRANCH FROM BUS i TO BUS j`.

C ABI 7 and PowerIO IR version 2 remain unchanged. The 0.11.5 IR catalog adds
no structural types; published schema snapshots retain their exact bytes.
PowerIO.jl 0.11.5 accompanies this release.

The [curated changelog](../../CHANGELOG.md#0115) records the complete changes.
