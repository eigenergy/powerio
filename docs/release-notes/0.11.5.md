# PowerIO 0.11.5 release notes

PowerIO 0.11.5 loads large CGMES datasets with a 1 GiB default input and
acquisition limit. Indexed import diagnostics and fresh emission reduce repeated
scans, and transformer terminals follow winding numbers even when terminal
sequence numbers differ. Python gains native component counts and source
severing for fresh export, and uses mimalloc for native allocations.

PSS/E RAW and RAWX switched shunts now interpret MODSW 1 as discrete voltage
control and MODSW 2 as continuous voltage control. Reparse the original case
if an older PowerIO IR document retained the reversed interpretation.

The paired release workflow freezes reviewed PowerIO and PowerIO.jl commits,
verifies the five binary assets, and tests the exact Julia candidate before a
human publishes the draft. The new workflow requires separate activation.

C ABI 7 and PowerIO IR version 2 remain unchanged. The 0.11.5 IR catalog adds
no structural types; published schema snapshots retain their exact bytes.
PowerIO.jl 0.11.5 accompanies this release.

The [curated changelog](../../CHANGELOG.md#0115) records the complete changes.
