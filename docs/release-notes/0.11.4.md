# PowerIO 0.11.4 release notes

PowerIO 0.11.4 stops counting out-of-service loads and shunts. The indexed
bus aggregates, and through them the Y-bus diagonal, the AC power flow
Jacobian, the DC and AC OPF preparations, the matrix pipeline sidecars, and
the GridFM bus table, now take in-service loads and shunts only, the rule the
power flow instances already applied to loads and generators. A network whose
loads and shunts are all in service builds exactly what it built before.
LinDist3Flow accepts meshed distribution networks, prepares neutral, switch,
line shunt, capacitor, load, and inverter data through a typed policy ladder,
and gains fixed-dispatch instance and solution types described by the
additive IR catalog `pio-ir/2/0.11.4`. Multiconductor solutions over more than
65,536 bus terminals read back through `deserialize`. A paired PowerIO.jl
checkout must bind or exempt every C entry point. C ABI 7 and PowerIO IR
version 2 remain unchanged.

The [curated changelog](../../CHANGELOG.md#0114) records this release's changes.
PowerIO.jl 0.11.4 accompanies this release.
