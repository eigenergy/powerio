# PowerIO 0.11.2 release notes

PowerIO 0.11.2 includes maintenance updates, regression coverage, and bundled
BMOPF schema snapshots with durable retrieval references. The historical
v0.1.0 baseline and proposed v0.2.0 profile remain distinct from Task Force
acceptance. C ABI 7 and PowerIO IR generation 2 remain unchanged.

The [curated changelog](../../CHANGELOG.md#0112) records this release's changes.
PowerIO.jl 0.11.2 accompanies this release.
