# Transformer reference values

`transformer_primitives.json` contains small synthetic cases written for this
project under MIT OR Apache-2.0, and numerical results generated by OpenDSS.
It contains no downloaded feeder data. The JSON records the exact engine version.

Regenerate with `opendssdirect.py==0.9.4` installed:

```sh
python evals/validation/generate_transformer_primitives.py
cargo test -p powerio-dist --test transformer_primitives
```

The cases cover two and three windings, WYE and DELTA connections, unequal taps,
floating neutrals, and omitted, zero, positive and negative `ppm_antifloat`.
The reference is OpenDSS's element terminal admittance, combined by physical
bus/terminal name. Ground rows are omitted. The Rust comparison also checks that
every reference terminal with a nonzero row exists in the calculated matrix.
These are element tests; a converged full-network power flow is checked separately
by consumers such as Tellegen.
