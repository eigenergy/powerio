# Python oracle dependencies for the validation harness. These are benchmark-only
# tools, NOT dependencies of a published PowerIO crate or the Python wheel. Install them into the
# same virtualenv that holds the powerio wheel:
#
#   .venv/bin/python -m pip install -r evals/validation/requirements.txt
#
# (The Julia oracle, PowerModels.jl, is likewise benchmark-scoped in
# evals/validation/Project.toml, not in any crate.)
# Use Python 3.12 or another Python >=3.11 for this oracle venv. Python 3.9 is
# still supported by the package, but PyPSA 1.x and some oracle pins no longer
# install there.
# Keep this in sync with the `bench` optional dependency in pyproject.toml.

# 3.4 or later, which pass matpowercaseframes a load engine object that only
# the 2.x line accepts.
